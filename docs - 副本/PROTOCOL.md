# UART v1 — 修订20串口/PC版

115200 baud，8 data bits，no parity，1 stop bit，单向 FPGA→PC。UART 分频1736，200 MHz下实际约115207.37 baud。无电脑控制信号源命令，信号模式由FPGA自动循环。

固定1330字节，小端。CRC16-CCITT，初始FFFF、多项式1021、不反射、无最终异或，覆盖偏移0..1327；低字节先发。收到坏CRC/非法长度/非v1时，解析器寻找下一个 `IQFT` 重新同步。

| 偏移 | 字节 | 定义 |
|---:|---:|---|
| 0 | 4 | ASCII `IQFT` |
| 4 | 1 | version=1 |
| 5 | 1 | bits1:0 模式；bit2 首样点活动；bit3 末样点活动 |
| 6 | 2 | 总字节数1330，即0x0532 |
| 8 | 4 | 选定帧号，uint32 |
| 12 | 4 | Fs=200000000，Hz |
| 16 | 2 | N=8192 |
| 18 | 2 | 主峰自然bin，0..8191 |
| 20 | 2 | 近似半功率连通区宽度，0..8192 bins |
| 22 | 2 | 活动点数量 |
| 24 | 2 | 窗口内活动首尾跨度 |
| 26 | 2 | 最长连续活动段 |
| 28 | 4 | uint25 最大时域I²+Q²，放在uint32中 |
| 32 | 5 | uint38 时域能量sum(I²+Q²)，高2位为0 |
| 37 | 1 | 主峰近似功率code |
| 38 | 4 | 输入首点→分析done的200MHz周期数 |
| 42 | 2 | 保留字段，本版固定为0 |
| 44 | 4 | 本次与上次选中帧之间跳过的帧数，首次为0 |
| 48 | 1024 | 256组 int16 I、int16 Q交错；12-bit数值正确符号扩展 |
| 1072 | 256 | 从-Fs/2到+Fs/2的256列频谱，32个bin最大值/列 |
| 1328 | 2 | CRC16，小端 |

主峰频率：`signed_bin=(bin<N/2 ? bin : bin-N)`；`f=signed_bin*Fs/N`。

宽度：`BW=bw_bins*Fs/N`，不是最外侧中心频率之差；因采用离散bin占用宽度，单bin宽度为Fs/N。

时域时间轴：`t[k]=k/Fs`，256点为连续样点，未抽取。

频谱列j覆盖FFT-shift后的 `[32j,32j+31]`，列中心为 `-Fs/2+(j+0.5)*Fs/256`；最大值可能出现在列内任一位置。

功率码和dBFS：见 `ARCHITECTURE.md`。dBFS参考2047²；0功率在PC中用很低的数值绘制，图窗下限-90dB，不表示硬件具有90dB动态范围。

导出得到三个文件：JSON元数据、`_time.csv`（time_s/I/Q）、`_spectrum.csv`（频率列中心/功率码/近似dBFS）。JSON标明数据来自演示还是硬件。

## 串口发送与快照释放

UART和分析器均使用200 MHz时钟。done置高后，元数据和两个快照RAM保持不变，直到sent单拍确认。sent只在完整的最后停止位结束后产生。顶层随即释放快照，分析器进入刷新等待，UART等待done下降后重新使能。

分频参数支持1..65536，默认1736；每个字符为1起始位、8数据位和1停止位，每位保持分频参数指定的时钟数。相邻字符额外保留5个空闲时钟用于准备字节。默认1330字节报文约需115.47725 ms，与分析器的57,458拍分析延迟分开计算。

偏移42..43保留，以兼容v1包长度与CRC位置。顶层将UART模块的旧panel_id兼容端口固定为0；新上位机命名为reserved并忽略其显示含义。没有屏幕检测逻辑。
