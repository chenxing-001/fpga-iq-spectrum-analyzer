# 修订23候选版数据路径与数值规则

## 数据路径

板载50 MHz → PLL 200 MHz → 内部IQ信号源 → 8192点radix-2² DIF SDF FFT → 快照分析器 → UART → PC。

信号源和FFT持续工作。分析器在满足刷新条件的帧首点选中一帧，统计完整时域窗口，等待对应FFT帧，写入8192点功率码RAM。随后扫描频谱、压缩为256列，并沿主峰两侧计算近似半功率连通带宽。

独立25位功率比较器保留峰值定位精度。两个交错累积通道保证每拍可接受一个有效样点；相等时选择最先到达的峰值。波形快照保留选定帧的前256个连续12位IQ样点。

## 流水线

- 平方和：私有A/B输入寄存 → 平方结果寄存 → 4组6位部分和寄存 → 25位功率寄存。输入样点到功率共4级，沿用修订19。
- I/Q与FFT两条功率路径的valid、index/bin、frame按修订19与功率同步；编码器仍为3级。原始256点时域快照在原接受沿写入，不经过功率流水。
- 修订19已在每个FFT旋转器的系数ROM输出后增加系数及前缀寄存，精确轴向旋转的数据、象限与valid同步延后1拍。六个旋转器总增加6拍，数值运算和吞吐率不变。
- 峰值比较维持两个交错通道和原有2拍反馈周期；8/8/9位局部比较及接受条件寄存后再归并，不对单个通道直接插入失配的流水线。
- 编码器判零/判一的高位条件延后至第2级归并，延迟仍为3级。

## UART握手与存储

所有分析、快照和UART逻辑使用同一200 MHz时钟。分析器置 `done=1` 后，元数据、256×24位时域快照RAM及256×8位频谱快照RAM保持不变。UART最后一个CRC字节的完整停止位结束后置 `sent=1` 一拍。顶层 `release_snapshot=done && sent`，分析器在下一时钟沿清除done，进入刷新等待。

UART在RELEASE状态等待done下降，避免重复发送。默认刷新等待0.2 s，随后等待新的帧边界。期间源和FFT不会停止；`frames_skipped`报告未被选作快照的帧数。

本版无显示双缓冲、显示格式化或跨时钟域邮箱。复位为异步置位、PLL锁定后在200 MHz域三级同步释放。发送中复位会取消当前不完整包，下一快照重新从帧头与CRC初值开始。

## 数值规则

- 输入和内部复数数据为有符号12位，范围−2048..2047。
- FFT每级缩放1/2，8192点总缩放约为FFT/N；截断采用算术右移，未加窗。满量程复数输入可能发生模4096回绕。
- 功率为I²+Q²，25位无符号；能量累加为38位。
- 活动判定为时域功率 **严格大于65536**。首末样点活动分别置clipped的低、高位。
- 活动点数为阈值以上样点总数；跨度为最后活动点−首个活动点+1；最长段为最长连续活动样点数。
- 峰值时域幅度为sqrt(max(I²+Q²))，RMS为sqrt(sum(I²+Q²)/8192)，单位为数字码值。
- 对非零功率P，功率码近似保留log2(P)的整数部分及3位尾数；PC按 `2^(code//8)*(1+(code%8)/8)` 近似还原。0码对应零功率。
- 带宽依据编码后的半峰功率门限扫描环形相邻bin，是量化后的近似半功率宽度。
- PC频谱显示为FFT-shift顺序的256组最大功率，每组32 bin；时域和频域的数据位置与修订16一致。

FFT窗口长度8192/Fs=40.96 µs。本版整机仿真确认默认分析延迟为57,460拍，按200 MHz换算为287.300 µs。该延迟包含FFT流水、分析扫描等流程，不等于UART发送耗时。

## 范围

该工程使用内部测试源，不含外部ADC接收或电脑反向控制。串口发送稀疏快照，无法承载全部200 MSPS原始数据。活动区间统计限定在当前FFT窗口内，不能据此推断被截断信号的完整协议帧长度。


修订20的峰值/计时控制沿用原设计。峰值比较改为8/8/9位分组，timer采用四字节分段进位；frames_skipped在帧接受后一拍更新。详见REVISION_20.md。

修订21只改变FFT b13（D=8）：两组4:1读取寄存 → 2:1组选寄存 → 加/减法寄存 → 输出与反馈写回。该级输出相比修订20固定增加2拍，连续输入吞吐不变；全部其他蝶形延迟不变。反馈地址至少8拍后重访，写回在请求后3拍提交，有效读取不会遇到同地址未提交数据。


修订22在旋转器现有最后两级内拆分加减法：第7级独立计算低11位进位/高12位部分和；第8级采用前缀AND/XOR修正进位，随后选择精确轴向输出。输出仅保留完整和的[22:11]位，与原算术右移后赋给12位输出一致。实部按p1+~p2+1分组，+1只放在低组。valid、exact标志和旁路数据均不新增流水级，完整FFT输出逐拍与修订21一致。


## 修订23候选版补充

修订22实测表明实部低组的三项加法被映射为两段串接进位链。修订23保持流水级数，仅将实部改为：低11位直接零扩展减法并寄存借位；高12位并行寄存 `Ahi-Bhi` 和 `Ahi+~Bhi`（即 `Ahi-Bhi-1`），下一拍按借位选择，再做原exact轴向旁路。虚部保持修订22实现。每个旋转器增加一个12位高组候选寄存器，RTL共72位；实际LE/寄存器由Quartus决定。算术模型检查通过；本轮没有执行RTL仿真、Quartus或板测，57,460拍为保持结构下的预期分析延迟。
